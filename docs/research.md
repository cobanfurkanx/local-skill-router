# Research attribution

The local prototype was informed by source-level investigation of these independent projects:

- [legendtkl/agentic-skill-router](https://github.com/legendtkl/agentic-skill-router), inspected at `160b30f0b67c923077f886376fdfae1016a70702`: local metadata retrieval, bounded discovery and reversible native catalogue suppression.
- [jax-agent/skill-router](https://github.com/jax-agent/skill-router), inspected at `fc0d038fb66787eaf983eeb8f05e1907fda46820`: lean routing instructions and local lexical search.
- [chrishan17/skill-router](https://github.com/chrishan17/skill-router), inspected at `02c01accaec681d8232e76ac7d1b6de3f86a98e0`: grouped discovery and invocation-suppression tradeoffs.

This repository packages the existing local Python implementation. The inspected repositories were not installed or executed as part of that investigation, no third-party skill corpus is redistributed, and this is not a claim of affiliation or comparative superiority. Automatic catalogue suppression and policy rewriting are deliberately absent from this portable package.
